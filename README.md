# SIGH V2 - Módulo de Emergencia y Archivos

Sistema hospitalario de gestión de atenciones de emergencia, monitoreo en tiempo real, pre-despacho y custodia física de historias clínicas.

## 🛠️ Stack Tecnológico
- **Backend:** Go (Fiber v2.52)
- **Bases de Datos:** Microsoft SQL Server (SIGH) & PostgreSQL (Auth)
- **Frontend:** HTML5, JavaScript ES6, Tailwind CSS v2.2.19, Chart.js
- **Servidor:** Ubuntu Server + Apache / Systemd Service

## ⚙️ Estructura del Repositorio
- `config/`, `controllers/`, `routes/`, `main.go`: API REST en Go.
- `frontend/`: Vistas y módulos consumidos vía cliente web.
